# Sravya Sri — Portfolio Website

A responsive, internship-focused portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For local development, use the VS Code Live Server extension if available.

## Before publishing — important updates
- Replace the GitHub profile links on project cards with each project's exact repository URL.
- Add live demo URLs where available.
- Replace `resume.pdf` with your latest resume whenever you update it; the hero already includes a resume download link.
- Confirm that your email, LinkedIn URL, education details, and project descriptions are current.
- Add screenshots of your actual projects to make the portfolio stronger.
- Review the wording of each project so it accurately reflects what you personally implemented.

## Publish with GitHub Pages
1. Create a new public repository named `sravyasri185.github.io` (or another repository name).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Files
- `index.html` — page structure and content
- `style.css` — layout, responsive design, animations
- `script.js` — navigation, role text animation, reveal-on-scroll, reading progress
